## Introduction
This project addresses the **Theory Track: Mapping the Phase Diagram of the ANNNI Model Under Noise**.  
The challenge is to explore the physics of the one-dimensional ANNNI (Axial Next-Nearest-Neighbor Ising) model and study how depolarizing noise affects its phase boundaries.  

We aim to:  
- Map the phase diagram of the ANNNI model in the \((\kappa, h)\) plane using PennyLane.  
- Introduce depolarizing noise on two-qubit gates and analyze distortions in the phase boundaries.  
- Identify which phases are most robust to noise and which are most fragile.  

Deliverables include:  
- Clean phase diagram (\(p=0\))  
- Noisy phase diagrams (\(p=0.01\), \(p=0.05\))  
- A 2–3 page writeup with methods, results, and physical interpretation  
- A 5–7 minute presentation  

Scoring emphasizes phase diagram accuracy, depth of noise analysis, physical insight, technical sophistication, and clarity of presentation. Bonus opportunities include detecting the floating phase, scaling to larger system sizes (\(N \geq 12\)), and implementing error mitigation strategies.
